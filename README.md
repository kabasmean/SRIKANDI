# KABAS MEAN

**Kanal Bantuan, Sumber Informasi, dan Media Panduan Penggunaan SRIKANDI**

Situs resmi: [kabasmean.my.id](https://kabasmean.my.id)

---

KABAS MEAN adalah kanal panduan penggunaan Sistem Informasi Kearsipan Dinamis Terintegrasi (SRIKANDI) untuk lingkungan Kabupaten Malaka, Dinas Perpustakaan dan Kearsipan.

Situs ini menyediakan:
- Panduan penggunaan SRIKANDI berdasarkan pengalaman nyata
- Kontak bantuan (WhatsApp) untuk pengguna yang mengalami kesulitan
- Informasi pembaruan versi SRIKANDI
- Dapat diakses tanpa koneksi internet setelah dibuka pertama kali (PWA)
